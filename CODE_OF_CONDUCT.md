# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be patient with people who are new to ADB or Android, criticise ideas and not
people, and assume good intent. Harassment, insults and personal attacks are not tolerated in issues,
pull requests, discussions or any other project space.

## Reporting

If someone behaves in a way that breaks these rules, report it privately to the maintainer through
[GitHub Security Advisories](https://github.com/nowaaak/quietv/security/advisories/new) or by direct
message on GitHub. Reports are kept confidential. The maintainer may remove content, warn, or ban
participants, following the enforcement guidelines of the Contributor Covenant.
