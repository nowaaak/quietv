# quietv CLI

Command-line companion for [quietv](https://github.com/nowaaak/quietv): back up, debloat and restore an
Android TV, Google TV or Fire TV over ADB, and install the quietv launcher. Pure Python, no `adb` binary
needed, works on Windows, macOS and Linux.

```bash
uv tool install "git+https://github.com/nowaaak/quietv#subdirectory=cli"
quietv --host 192.168.1.50 probe
```

See the main [README](https://github.com/nowaaak/quietv#readme) for the full guide.
